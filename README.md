
# 心脑血管健康营 H5

基于 `versionall` 健康训练营 H5 的增量改造版本，保留原有页面结构、Vant 组件与微信内 H5 交互，仅调整品牌色、角色与心血管业务内容。

- 品牌：北大医疗 · 心脑血管健康营
- 主色：医疗蓝 `#0B5FD7`
- 端：学员 / 运动康复师 / 医师 / 营养师
- 管理端：集团一级管理员 / 医院二级管理员
- 演示登录：手机号 + 验证码 `123456`
  - 学员 `13800000001`
  - 医师 `13600000001`
  - 运动康复师 `13700000001`
  - 营养师 `13900000001`
  - 一级平台管理员 `18888888888`
  - 医院管理员 `13500000001`（北大医疗康复医院）
  - 医院管理员 `13500000002`（北大医疗淄博医院）
  - 运营督导 `13900000009`

演示口径：

- 四端随访使用同一浏览器内的持久化演示会话，用于验证医生、康复师、营养师、学员互通与留痕。
- 管理端从登录页“管理端登录”进入；一级管理员可查看全集团，二级医院管理员仅可查看本院。
- 权限按“医院 + 角色”配置，绑定菜单入口和关键操作（处方签署、饮食/运动批注、随访发送、账户操作、报告导出等）。
- 个人与机构报告以血压、LDL-C、静息心率、同型半胱氨酸、运动安全、随访和用药为主；体重仅作体液潴留参考。
- 正式上线需接入 IM 服务端、跨设备消息同步、医生/机构实名与权限校验、检查报告对象存储及 72 小时心电设备数据。
- 账户管理演示两级权限：平台管理员可配置积分/活动/兑付规则；机构管理员只能管理本机构营期与人员。

本地开发：

```bash
npm install
npm run dev
```

构建：

