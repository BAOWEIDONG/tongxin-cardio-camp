# 心脑血管健康营 H5 Demo

北大医疗 · 心脑血管健康营的独立前端 Demo，基于 `versionall` 健康训练营 H5 做增量改造，保留 Vant + 微信内 H5 的交互和页面结构，主色使用医疗蓝 `#0B5FD7`。

- 独立仓库：`BAOWEIDONG/tongxin-cardio-camp`
- 演示地址：https://baoweidong.github.io/tongxin-cardio-camp/
- 适用人群：已确诊高血压、颈动脉斑块、LDL-C 偏高或其他心血管慢病人群
- 营期结构：21 天集中活动 + 后续 11 个月线上长期管理

## 四端服务流转

- 学员：手机号+角色准入 → 心脑血管专项问卷 → 病历/化验/心电材料上传 → 知情同意 → 绑定营期 → 心血管健康档案 → 运动/饮食/体重/家庭血压打卡 → 查看运动与营养处方、团队批注 → 在线随访 → 活动/小红花/奖励 → 个人营期报告。
- 医师：患者风险分层 → 复核入营资料与用药 → 录入开营/第 6 个月/结营三阶段指标 → 复核并签署运动处方 → 线上随访、干预方案与复查结论 → 查看康复师/营养师批注。
- 运动康复师：运动能力评估 → 提交个体化运动处方 → 医师签署后同步学员 → 逐条运动批注/评分 → 第 6 个月复评。
- 营养师：营养评估 → 结合血压、血脂、肾功能和用药发布饮食处方 → 三餐批注/评分 → 低盐少油与用药-饮食相互作用提示 → 奖励/兑换发放。
- 管理端：一级集团管理员配置全集团规则、活动、小红花、兑付与运营总览；二级医院管理员配置本院人员、营期、团队菜单和按钮权限。

四端随访共用同一个学员-营期会话：学员、医师、康复师、营养师均可查看并回复，消息与处方发布、医师随访记录统一留痕。

## 权限与数据隔离

- 权限按“医院 + 角色模板”下发，同时控制菜单入口和关键操作（随访发送、运动/饮食批注、运动处方提交/签署、营养处方发布、三阶段指标录入、账户/营期/报告等）。
- 一级管理员拥有全量权限，可切换并配置所有医院；二级管理员只能配置本院，且平台级规则只读。
- 团队成员权限跟随所属医院，不能跨院查看患者、营期、随访或报告。
- 管理员账号在登录页使用独立入口，不与学员/医师等业务角色混用。

## 心血管口径

- 核心指标：血压、LDL-C、静息心率、同型半胱氨酸、血糖/HbA1c、肝肾功能、腰围、BMI；支持开营/第 6 个月/结营三阶段录入，并统一同步到档案、患者列表和个人/机构报告。
- 报告重点：血压与 LDL-C 达标趋势、运动安全、随访覆盖、用药与低盐少油执行；体重只用于观察水肿、心衰和体液潴留风险，不作为主疗效指标。
- 运动强度统一使用 1–5 级 RPE：常规 `2–3 级`，恢复期 `1–2 级`，不使用 Borg 6–20 或 `RPE 11–13`。
- 互联网医院只做第三方平台跳转入口，不承诺免费无限次问诊；本 Demo 不模拟真实开药、门诊诊断或 72 小时心电设备数据。

## 线上/线下边界

线上已完成：准入、问卷、材料归档、知情同意、三阶段档案、家庭血压、运动和饮食打卡、双处方、批注、四端随访、活动/小红花/商城/奖励、个人与机构报告、权限和账户管理。

线下只做结果归档和状态衔接：到院抽血、心电图/72 小时心电、医师门诊、康复评估、开药和随访检查不在 H5 内模拟。Demo 中保存“线下检查留档/线上复评”状态，避免把线下医疗行为做成线上自动诊断。

## 数据与演示限制

- 当前是纯前端 Demo，数据保存在同一浏览器的 `localStorage`，用于验证同浏览器内换角色、刷新后的流程闭环。
- 数据版本为 `v11`：会自动清理旧减重/燃脂徽章和奖品，迁移旧运动类型与文案，并保留账户、兑换和领取记录。
- 正式上线需接入真实后端、统一登录与实名/机构校验、IM 服务端与跨设备消息、检查报告对象存储、审计日志、库存/物流接口及互联网医院跳转协议。
